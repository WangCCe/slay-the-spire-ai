## Why

The registered ten-game fresh replay passed every zero-update, callability,
trace, inventory, boundary, and runtime check, yielding 350 direct and 502
changed-proposal decision starts. The remaining step is to execute the already
frozen abstaining-residual recipe once and decide whether it controls direct
drift while learning material changed-proposal corrections.

## What Changes

- Add a source-bound CPU runner for the fixed frozen-parent residual recipe.
- Consume only the qualified `ba02c749...` checkpoint and reject the closed R1
  checkpoint or any altered registration, cohort, recipe, threshold, or source.
- Train exactly 128 optimizer steps with 32 direct and 32 changed spans per
  batch, then publish partitioned gate, action, TD, End Turn, integrity, and
  serialization evidence.
- Create a runner-binding supplement before execution and run the fit at most
  once. A failure closes the corpus without retry or tuning.

Success requires every preregistered technical gate to pass. A pass grants only
eligibility for a separately registered fresh holdout; it does not establish
policy quality, authorize production loading, or replace r16.
