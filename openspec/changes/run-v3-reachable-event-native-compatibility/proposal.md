## Why

The source-complete reachable-event contract and v3 bridge now cover all 48
registered event-option targets, but the only native compatibility cohort is
the consumed `7000..7007` failure against the predecessor 25-event resolver.
A separate immutable cohort is required to prove that the new resolver works on
native own trajectories before it can support any baseline-floor or RL
readiness decision.

  pushed reachable-event resolver, bridge, API v3 native module, simulator
  physical source identity, metadata, runtime, output contract, and all-false
  authority without modifying the frozen predecessor evaluator or evidence.
- Perform a read-only inventory of every consumed, selected, reserved,
  training, validation, compatibility, and final-test seed named by repository
  registrations before choosing one deterministic fixed cohort of untouched
  seeds. Publish and push the exact seed ledger and registration before any

- Run the registered cohort once with two deterministic replays, bounded target
  decisions and wall time, exact legal action mapping, source non-mutation,
  terminal completion, and aggregate route/shop/event/card-reward coverage.
  Persist whole-cohort consumption before the first environment and preserve
  the first blocker as a valid negative without retry, replacement, or tuning.
- Publish canonical configuration, journal, rows or failure, metrics, report,
  and manifest, then verify them without loading the native module. The success

- Keep gameplay, baseline-floor, reward, model, OPE, formal RL, training,
  qualification, loading, and promotion out of scope. Rollback removes only the
  new evaluator and successor evidence while preserving the source audit, v3
  resolver, predecessor contract, and consumed `7000..7007` failure unchanged.
