## Why

The recovered teacher audit closes state/action source fidelity but rejects
SimpleAgent as a policy-quality gate, while the frozen outcome feasibility,
baseline, and OPE artifacts remain negative or non-authorizing. Those component
results are not yet combined by one reproducible contract that answers whether
a bounded formal non-combat RL training proposal may even be considered.

## What Changes

- Add a registered, read-only synthesis audit that hash-binds only frozen
  state/action, teacher, reward, simulator-baseline, outcome/support, and
  untouched-evaluation evidence.
- Define fixed readiness gates for state/action closure, representation and
  teacher use, reward semantics, credible baseline floor, outcome/propensity
  support, deterministic reproduction, and evaluation isolation.
- Publish one hash-closed verdict: invalid evidence, blocked with explicit
  prerequisites, or ready only for a separate bounded-training proposal.
- Keep Current, Bottled, and SimpleAgent as auxiliary references rather than
  reward or policy-quality truth, and preserve simulator/live evidence as
  separate evidence classes.
- Run no gameplay, simulator rollout, native module, model fitting, reward
  change, OPE reinterpretation, formal RL, qualification, or promotion.

There is no new live evidence. Success means the same registered frozen bytes
reproduce the same gate matrix, blockers, verdict, authority, and manifest. A
positive verdict would authorize only a separately reviewed training proposal;
it would not authorize training or live loading.

## Capabilities

### New Capabilities

- `noncombat-formal-rl-readiness-audit`: Defines frozen evidence bindings,
  cross-domain readiness gates, deterministic no-authority publication, and the
  handoff boundary for any later bounded formal-RL proposal.

### Modified Capabilities

None.

## Impact

- Adds one offline analysis script, focused tests, a frozen registration, and
  canonical JSON/Markdown readiness artifacts.
- Reads existing repository reports and manifests without modifying their
  bytes, the active outcome-evidence study, live configuration, game state,
  external simulator checkout, checkpoints, or policies.
- Changes no production agent, adapter, reward, model, estimator, training
  entrypoint, or promotion gate. Rollback removes only this change, analyzer,
  tests, registration, and generated synthesis artifacts.
