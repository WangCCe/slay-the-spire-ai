## 训练公式详解

### Q-Learning 更新公式

```
Q(s,a) ← Q(s,a) + α [r + γ * max Q(s',a') - Q(s,a)]
```

**含义**：
- `Q(s,a)`：在状态s做动作a的价值
- `r`：立即奖励
- `γ`：折扣因子 (0.99)，未来的奖励不如现在重要
- `max Q(s',a')`：在下一状态s'做最好动作的价值
- `α`：学习率 (1e-4)

**直观理解**：
```
新估计 = 旧估计 + 学习率 × (实际体验 - 预期)

实际体验 = 立即奖励 + 未来的最大价值
预期 = 旧的价值估计

如果实际 > 预期 → 提高Q值（这个动作比想象好）
如果实际 < 预期 → 降低Q值（这个动作比想象差）
```

### Huber Loss

```python
def huber_loss(error):
    if abs(error) < 1.0:
        return 0.5 * error^2      # 小误差：平方（MSE）
    else:
        return abs(error) - 0.5   # 大误差：线性（MAE）

# 优点：
# ✅ 对异常值鲁棒
# ✅ 训练稳定
```

## 超参数配置

| 参数 | 值 | 说明 |
|------|-----|------|
| **学习率** | 1e-4 | 每次更新的步长，太小学习慢，太大不稳定 |
| **折扣因子 γ** | 0.99 | 未来的价值权重，越大越看重长期收益 |
| **批大小** | 128 | 每次训练用多少样本 |
| **缓冲区大小** | 100,000 | 最多存储多少经验 |
| **目标网络更新频率** | 1000步 | 每1000步同步一次目标网络 |
| **训练频率** | 4步 | 每4步训练一次网络 |
| **探索率衰减** | 50,000步 | 从1.0衰减到0.1需要50000步 |
| **最终探索率** | 0.1 | 始终保留10%探索 |

## 时间线示例

```
Step 0-1000:   探索期 (ε=1.0)  - 完全随机动作，收集多样化经验
Step 1000-10000: 学习期 (ε=0.8-0.5) - 开始利用已学知识
Step 10000-50000: 精进期 (ε=0.5-0.1) - 逐渐减少探索
Step 50000+:    成熟期 (ε=0.1) - 主要利用，少量探索

预期胜率:
- 1000步:  5-10%  (比随机好一点点)
- 10000步: 20-30% (学会了基本策略)
- 50000步: 40-50% (接近人类水平)
- 100000步: 50-60% (可能超越新手)
```

## 性能瓶颈

1. **训练时间**
   - 每局游戏: ~10分钟
   - 10,000局: ~70天
   - 解决：多线程训练、分布式训练

2. **样本效率**
   - DQN 需要大量样本
   - 解决：优先经验回放(PER)、双DQN

3. **探索效率**
   - 随机探索效率低
   - 解决：好奇性驱动、逆强化学习

## 下一步优化方向

1. **算法改进**
   - Double DQN: 解决过估计问题
   - Dueling DQN: 分离状态价值和动作优势
   - Rainbow DQN: 集成多种改进

2. **特征工程**
   - 更详细的手牌特征
   - 完整的卡组组成
   - 怪物意图特征

3. **训练加速**
   - 并行游戏环境
   - GPU 加速批量计算
   - 分布式训练
